如何避免“看似高胜率”的回测陷阱？

严格隔离样本

按日线时间顺序70%训练、30%样本外。训练段信号若在分界线后才满20/60/120日则剔除，不把测试段价格偷算进训练段。EMA仅使用当日及此前收盘，所有组合统一先经过200个交易日预热。

区分胜率与收益、次数与独立性

金叉可能连续相邻或在固定持有期内重复发生，原始事件不是独立试验；核心结果优先取60交易日内不重复开仓的事件。最大回撤来自每日按市值标记的模拟权益曲线，不等于单笔最大亏损。

不是优化参数

EMA20/50、EMA20/60、MA60/200是你事前选定的三个组合；不会事后搜寻数百组参数并只报最高胜率。最终仍需跨周期、跨市场和滚动样本外验证。

风险与限制

仅研究指数日收盘价格，不考虑交易日次日开盘跳空及盘中成交可行性、ETF溢折价、停牌和追踪差异。样本外不等于未来有效，历史上涨概率绝非下一次交易成功概率。

数据质量声明：本网页不含预置或伪造的胜率。只有 GitHub Actions 成功抓取指数历史真实日线、与现有日线交叉核验、满足样本数门槛后才输出数值。不同数据源失效、历史不足、节假日行情滞后时明确提示。

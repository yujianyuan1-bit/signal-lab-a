## 自动采集

`pip install -r requirements.txt` 后运行 `python update_data.py`。
原GitHub Actions定时配置保留。十维公开数据无需Tushare Token。
`research_factors.py`供主脚本调用，结果保存在`data.js`的`research`字段。

| 维度 | 来源与实际范围 |
| --- | --- |
| 估值位置 | 国证/中证指数当前PE；绝对PE规则，不是历史百分位，也不与旧等权PS拼接 |
| 盈利表现 | 当前成分股同一报告期已披露净利润同比，至少80%覆盖；不是预测修正 |
| 宏观流动性 | M2同比和一年LPR较3期前变化；未覆盖完整社融/信用脉冲 |
| 市场广度 | 当前成分股MA60比例及5日变化，同一篮子同一组有效股票，至少90%覆盖 |
| 量价结构 | 优先指数真实成交额；缺失时使用有明确标签的单只ETF代理 |
| ETF份额 | 交易所单只观察ETF连续6交易日份额；最多容许2交易日披露滞后，显示实际日期 |
| 融资杠杆 | 原板块样本融资余额与同期价格；保留原300/301及688/689聚合范围以保持历史一致 |
| 价格趋势 | 原指数日线、MA20/60和5日涨幅规则 |
| CVD真实订单流 | 无授权真实逐笔时缺失；分钟PVD独立展示，不替代CVD计分 |

每项输出`status/score/date/source/rule/scope/checked_at`，部分另含覆盖率、
报告期或滞后天数。失败时`score=null`，旧成功观察仅存为`last_good`供审查。
采集任务成功不等于十维成功，检查`research.health`及页面健康面板。
成分股前复权日线缓存随`data.js`保留，已核实的融资历史继续增量回填。

网页v2评分状态不会继承v1占位分；旧浏览器v1记录仍保留。
手动覆盖显示为手动判断，14自然日后停用，可按“恢复本项自动数据”退出覆盖。
原行情、均线回测、分钟PVD和融资压力实验室保持独立。

十维是透明的研究映射，不是收益概率；当前成分名单、估值、财报和宏观数据
没有历史时点版本，不能拿当前值倒填历史或宣称十维已完成收益回测。

## 第十项：风格相对强弱

新增`relative`，观察上证指数/创业板指、上证指数/科创50比值。
比值下降代表目标相对更强；水平值受指数基点影响，不用于跨指数比较。
只用严格共同交易日，基准停更或任一日期缺失时停用，不填充旧价格。

候选规则为`5+0.5×20日目标/上证相对涨幅%+0.2×5日相对涨幅%`，限制1–10。
该规则尚未证明能改善完整综合8分入场胜率，因此默认权重0%，作为观察项显示。
它不是BTC市值占比意义上的dominance，也不是资金净流入。与价格趋势有明显相关性，
不能不经验证重复加权。前端保留既有手动权重，新项默认0不改变原综合分。

健康面板按10项统计可用观测，评分参与项仅统计正权重；因此可能显示9/10项可用、
8/10项参与评分（真实CVD缺失，相对强弱为0权重）。

本轮1000日回测为独立研究，尚未加入每日线上采集依赖。
生产采集不运行训练或参数搜索。
当前原始九因子历史不足，不能将两因子或三因子诊断误标为完整系统胜率。
